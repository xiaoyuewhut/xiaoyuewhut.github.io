## 文献筛选标准

- 优先选择顶级综合期刊、顶级心理学期刊、顶级医学期刊与高影响力教育、发展、经济学期刊。
- 避免把原生 OA 期刊作为主文献池。
- 如果正式出版页受限，优先收录作者 accepted manuscript、机构仓储版本或合法公开副本。
- 主题覆盖四类：
  - 遗传与基因环境交互
  - 孕期、早期营养、家庭与社会经济环境
  - 智商与学校教育、学历、考试成绩的关联
  - 中国与海外样本的异同

## 核对规则

- 下载后统一放到 `参考文献/智商调研/`。
- 文件名尽量使用“标题主干 + 期刊或主题”的可读命名，后续核对更省事。
- 如果下载结果是网页、登录页或只有 1 页的占位 PDF，不要直接算完成。
- 落盘后可用 `file 参考文献/智商调研/*.pdf` 快速筛掉伪 PDF。
